2. Создайте systemd-сервис для Gunicorn

```bash
sudo nano /etc/systemd/system/gunicorn.service
```

Вставьте туда вот этот код, подставив свои пути:

```ini
[Unit]
Description=gunicorn daemon for Django project
After=network.target

[Service]
User=ваш_пользователь
Group=www-data
WorkingDirectory=/home/ваш_пользователь/путь_к_проекту
ExecStart=/home/ваш_пользователь/путь_к_проекту/venv/bin/gunicorn \
    --workers 3 \
    --bind unix:/home/ваш_пользователь/путь_к_проекту/gunicorn.sock \
    ваш_проект.wsgi:application

Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Что поменять:

· ваш_пользователь — имя пользователя, под которым вы работаете.
· путь_к_проекту — полный путь к папке с вашим проектом.
· ваш_проект.wsgi — название папки проекта (где wsgi.py), например myproject.wsgi.

---

3. Запустите и активируйте сервис

```bash
sudo systemctl daemon-reload
sudo systemctl start gunicorn
sudo systemctl enable gunicorn  # чтобы запускался при загрузке
```

Проверьте статус:

```bash
sudo systemctl status gunicorn
```

Должно быть active (running). Если ошибка — проверьте логи:

```bash
sudo journalctl -u gunicorn
```

---

4. Настройте Nginx

Отредактируйте ваш конфиг Nginx (тот, что вы создавали ранее):

```bash
sudo nano /etc/nginx/sites-available/redirect
```

Полностью замените содержимое на:

```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;

    location /static/ {
        alias /home/ваш_пользователь/путь_к_проекту/static/;
    }

    location /media/ {
        alias /home/ваш_пользователь/путь_к_проекту/media/;
    }

    location / {
        include proxy_params;
        proxy_pass http://unix:/home/ваш_пользователь/путь_к_проекту/gunicorn.sock;
    }
}
```

---

5. Соберите статику Django

```bash
cd /home/ваш_пользователь/путь_к_проекту
source venv/bin/activate
python manage.py collectstatic
```

Убедитесь, что в settings.py указано:

```python
STATIC_URL = '/static/'
STATIC_ROOT = '/home/ваш_пользователь/путь_к_проекту/static/'
```

---

6. Дайте права доступа

```bash
sudo usermod -a -G www-data ваш_пользователь
sudo chown -R ваш_пользователь:www-data /home/ваш_пользователь/путь_к_проекту
sudo chmod -R 755 /home/ваш_пользователь/путь_к_проекту
```

---

7. Перезапустите Nginx

```bash
sudo nginx -t          # проверить конфиг
sudo systemctl reload nginx
```

---

8. Финальная проверка

Откройте браузер и перейдите на http://ip_вашей_ВМ. Должен открыться ваш Django-сайт!

Если видите 502 Bad Gateway — Gunicorn не запустился или не видит сокет. Тогда:

```bash
sudo systemctl status gunicorn
sudo journalctl -u gunicorn -n 50
```

Если видите 404 Not Found — проверьте пути в Nginx (особенно root и alias).
